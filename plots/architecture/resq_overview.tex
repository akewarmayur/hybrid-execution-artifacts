\caption{
\textbf{RES-Q overview.}
After an interruption, RES-Q reconstructs the latest valid semantic restart
boundary. Recovery restores workflow state and decision evidence, but does not
itself justify continuation. RES-Q compares relevant saved evidence with the
current execution context and selects replay, migration, or block. We evaluate
both the useful work preserved and the quality and cost of this decision.
}
