# RQ4 Policy Analysis

Offline analyses over frozen calibration and held-out evaluation records:

- eight-policy comparison;
- learned Logistic Regression baseline;
- hindsight Oracle;
- pairwise bootstrap comparisons;
- 67-vector score-weight sensitivity.

`processed/` contains derived records, `final_validation/` contains publication-facing results, and `scripts/` contains the generators and validators. No script in this directory submits simulator or hardware jobs.
